Origem dos Dados Brutos
  • 📌 SIM (Sistema de Informações sobre Mortalidade): Dados primários de óbitos coletados das Declarações de Óbito (DO). Mantido pelo Ministério da Saúde.
    🔗 Acessar base do DATASUS (TABNET)
  • 📌 IBGE (Instituto Brasileiro de Geografia e Estatística): Códigos territoriais utilizados para o georreferenciamento dos municípios do Triângulo Crajubar.
    🔗 Acessar portal IBGE Cidades
  • 📌 CID-10 (Classificação Internacional de Doenças): Dicionário médico global da Organização Mundial da Saúde (OMS), utilizado para categorizar as Causas Básicas.
    🔗 Acessar plataforma oficial da OMS
Metodologia do Sistema

O processamento ETL (Extract, Transform, Load) foi desenvolvido em Python (Pandas). A "Linha de Base" estatística utiliza a média histórica do triênio 2017-2019 para cálculo de Excesso de Mortalidade local. O "Z-Score" para detecção de anomalias no Robô Analítico foi estipulado com limite de alerta para 2+ desvios-padrões da média da série temporal.
